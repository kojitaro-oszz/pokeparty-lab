# てもちびるだー（旧仮称：PokéParty Lab）

ポケモン本編シリーズ向けの、手持ちパーティ構築・タイプ相性分析Webアプリです。
スマートフォン・iPad・PCのブラウザで動きます。個人（自分と友達）で使う非営利のファンメイド作品です。

> 非公式ファンプロジェクトです。任天堂・ゲームフリーク・クリーチャーズ・株式会社ポケモンとは一切関係ありません。
> ポケモンに関する名称・権利は、それぞれの権利者に帰属します。

## 公開URL

`https://kojitaro-oszz.github.io/pokeparty-lab/`

## できること（動作確認済み）

- 作品の選択（第1世代／第2〜5世代／第6世代以降の3方式でタイプ相性を計算）
- ポケモンの検索（日本語名で全ポケモン／ひらがな可）と、PokéAPIからの追加
- ポケモン画像の表示
- 作品ごとの「登場／図鑑外」表示と絞り込み（その作品の地方図鑑に載っているかで判定）
- 手持ち6匹の登録・削除・並べ替え
- 弱点・耐性・無効の一覧、弱点の集中、攻撃面で抜群を取れないタイプの表示
- パーティの保存・複製・削除（ブラウザ内に保存）
- 図鑑：選んだ作品の地方図鑑を一覧表示（タップで追加）
- 技検索：日本語の技名から、覚えるポケモンを一覧（作品ごとの習得確認つき）
- 詳細ページの「役割」「おすすめ持ち物」（目安）
- パーティの書き出し／コピー／読み込み
- 役割シミュレーター：手持ちの役割分担の診断と、起点作り→積みの流れのシミュレーション（目安）
- 縛りプレイ設定：ポケモンの固定（🔒）、同じタイプの上限（タイプかぶりなし等）、使用禁止タイプ。違反の表示と、提案への反映
- 入れ替え提案（タイプ相性と図鑑登場で判定。目的に応じて基準を切り替え）
- 詳細ページ：種族値、特性（効果説明つき）、覚える技（タップで効果表示）、進化と条件、性格一覧（PokéAPIから取得）
- 画面は「編成」「分析・提案」「保存・情報」のタブと、折りたたみで見やすく整理

## まだできないこと・未検証

- 入手時期・育成難易度・種族値・技構成を使った評価
- 入れ替え提案の候補はサンプル24匹のみ
- エクスポート／インポート
- おすすめの技構成・性格・入手方法・厳選手順
- 種族値・進化条件は最新作の値です。作品ごとの違いは未検証です。
- 第1世代・第2〜5世代・第6世代以降以外の細かな仕様差、Let’s Go・LEGENDS アルセウスの特殊仕様は未対応です。
- データが取得できない場合は「未確認」または「取得できません」と表示します。

## 使い方

公開URLを開くだけで使えます。インストールは不要です。
iPhone/iPadでは、Safariの共有ボタンから「ホーム画面に追加」すると、アプリのように起動できます（アイコン：`apple-touch-icon.png`）。

## 公開方法（GitHub Pages）

1. このリポジトリの `index.html`、`apple-touch-icon.png`、`icon-192.png`、`icon-512.png`、`manifest.webmanifest` を、リポジトリの一番上の階層に置きます。
2. 「Settings」→「Pages」→「Branch」を `main` にして「Save」。
3. 1〜2分後に公開URLが表示されます。

ビルドやサーバーは不要です（`index.html` 1ファイルで動作します）。

## データの出典

- ポケモンの名前・タイプ・種族値・特性・技・進化は、公開API [PokéAPI](https://pokeapi.co/) から実行時に取得しています。取得したデータはお使いの端末のブラウザ内にキャッシュ（保存）します。
- 日本語名の一覧は、PokéAPIのリポジトリ（PokeAPI/pokeapi）のCSVから取得しています。
- ポケモン画像は、PokéAPIの画像リポジトリ（PokeAPI/sprites）から表示しています（このリポジトリにはコピーしていません）。画像の権利は各権利者に帰属します。
- 入れ替え提案用のサンプル24匹のデータは手入力です（公式データとの照合は未完了）。
- タイプ相性表は手入力で、検証用のテストを行っています。

PokéAPIの利用条件は、公式サイトの案内をご確認ください：https://pokeapi.co/docs/v2

## 利用上の注意

- 表示内容は正確さを保証しません。ゲーム内の実際の挙動と異なる場合があります。
- 秘密情報（APIキー等）は使用していません。リポジトリに含めないでください。
- 保存したパーティはブラウザ内にのみ保存されます。ブラウザのデータを消すと失われます。
